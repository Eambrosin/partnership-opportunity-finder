# v3.0.0 — Route-to-Market & Partner Intelligence

## Release Summary

Version 3.0 positions PARTNER as the route-to-market branch of the shared Commercial Mandate Workspace.

The application combines explainable partner scoring with practical execution-readiness due diligence and preserves the same client, corridor, product and route-to-market context across the workflow.

## Highlights

- new product positioning: Route-to-Market & Partner Intelligence
- shared private Commercial Mandate Workspace
- Supabase-backed mandate persistence
- protected Private Workspace Access
- automatic `mandate_id` restoration
- mandate-safe pipeline behavior
- no demo partnership data mixed into an active mandate
- strategic-fit and market-access scoring
- Route-to-Market Readiness
- customer-base and geographic-coverage assessment
- import capability
- technical service and after-sales capability
- installation / commissioning capability
- spare-parts and field-service capability
- financial capacity and management commitment
- exclusivity / competing-representation validation
- explicit due-diligence gaps
- ENGAGE handoff under the same mandate
- automated tests, CI and secret scanning

## Commercial Workflow

```text
IDENTIFY / PRIORITIZE
        ↓
      PARTNER
        ↓
Route-to-Market Due Diligence
        ↓
      ENGAGE
```

## Design Principles

A strategically attractive organization is not automatically an executable partner. Unknown due-diligence fields remain visible gaps rather than being silently scored as positive evidence.
